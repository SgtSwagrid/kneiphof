AnyGraph

com.alecdorrington.kneiphof.AnyGraph
See theAnyGraph companion object
trait AnyGraph[+V, +E, M]

A graph of any kind, with vertices of type V, edge labels of type E and edge multiplicities in M.

Each edge value has a multiplicity, and is present exactly when its multiplicity isn't zero (see Multiplicity).

Two graphs are equal when they belong to the same family, being both directed or both undirected, with the same multiplicities, and have the same vertices and the same multiplicity for every edge. This is how Scala's collections compare within a family, so that List() == Vector() but Set() != List(). So a graph equals the hypergraph with its edges, and a lazy graph equals its materialisation, but an edgeless graph doesn't equal an edgeless directed graph or multigraph.

A graph known to have more vertices than an Int can count can only be compared with a graph built the same way, such as an equal grid, or with one known or found to have fewer vertices. Comparing it with any other graph throws an UnsupportedOperationException, since that would mean listing more vertices than a set can hold. Such graphs hash only their order, so they can be kept in hash sets and maps, alongside graphs built the same way.

Throws
UnsupportedOperationException

If either graph is known to have more vertices than an Int can count, the two aren't built the same way, and the other isn't known or found to have fewer vertices, since then they could only be compared by listing more vertices than a set can hold. Two lazy graphs whose orders aren't known are compared by listing them, however large they are.
