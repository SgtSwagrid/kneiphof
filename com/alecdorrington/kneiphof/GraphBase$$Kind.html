def complete(sizes: Int*): [v, e] =>> GraphBase[v, e, M][Int, Unit]

Attributes

Returns

The complete graph with parts of the given sizes, following the notation K_n, K_{m, n}, and so on, on the vertices 0, 1, .... A single size n gives the complete graph on n vertices, in which every two vertices are adjacent. Several sizes give the complete multipartite graph, whose vertices are split into parts of those sizes in order, and in which every two vertices in different parts are adjacent. Adjacent vertices are joined both ways, for directed graphs. So complete(3, 4) is the complete bipartite graph, and complete(1, 1, 1) is complete(3).

def petersen(n: Int, k: Int): [v, e] =>> GraphBase[v, e, M][Int, Unit]

Attributes

Returns

The generalised Petersen graph GP(n, k), whose outer vertices 0 until n form a cycle, each joined by a spoke to the inner vertex n + i, and in which each inner vertex n + i is adjacent to n + i + k, going round modulo n. k must be at least 1 and less than n / 2. So petersen(n, 1) is a prism, and petersen(10, 2) is the dodecahedron.
